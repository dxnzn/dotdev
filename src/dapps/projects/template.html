DNZN // WNS Resolver browser extension

Chrome extension that detects ethereum addresses on any page and resolves them to their Wei Name Service (WNS) primary names in-place.

  • Batched resolution via Multicall3 — multiple addresses resolved in a single RPC call
  • Robust set of configuration options — custom rpc, caching, cooldown, etc
  • Zero external dependencies — vanilla javascript, no build requirements

Production deployment is pending feedback and testing — development installation via git.
